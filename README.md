# Sarthak Portfolio — Hybrid Motion Redesign

A React + Vite portfolio concept with a continuous editorial layout, oversized typography, ivory/gold/espresso palette, GSAP motion, and a horizontal process-story section on desktop.

## Run locally

1. Extract the project folder.
2. Open the folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Run:

```bash
npm install
npm run dev
```

5. Open the localhost URL printed by Vite.

## Notes

- The process section scrolls horizontally on desktop while the rest of the site scrolls vertically.
- On touch devices, that section becomes a swipeable horizontal rail.
- Reduced-motion preferences are respected.
- Contact form is currently a front-end design only; email delivery still needs a serverless endpoint and provider configuration.
- Replace the generic LinkedIn / WhatsApp / email destinations with the actual profile and contact details before publishing.
